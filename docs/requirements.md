## 2. 機能仕様の詳細

### 認証方式
- **方式**: 名前入力のみ
- **重複**: 同じルーム内では許可しない（先着順）
- **名前制限**: 2文字以上20文字以下、日本語・英語・数字を許可

### ルーム管理
- **ルームコード**: 20文字、英数字を使用
- **同時接続上限**: 20人（今後変更の可能性あり）
- **ルーム有効期限**: 30分（今後変更の可能性あり）

### お題管理
- **お題**: 事前定義、JSONなどでコード管理
- **カテゴリ分け**: 不要（全ルーム共通・全モード共通）
- **お題制限**: 30文字以下、日本語・英語・数字・記号を許可

### ゲームモード
- **一致モード（`match`）**: 全員一致を目指す。判定は「全員一致 / 全員一致ならず」。AI の会話のヒントを利用可
- **不一致モード（`mismatch`）**: 参加者特有の回答を集めて雑談を生むことが狙い。判定は「被りなし / 被りあり」。AI の会話のヒントは使わず、固定文「気になる回答の人に理由を聞いてみましょう」を表示
- **選択タイミング**: ルーム作成時に選択。主催者は待機中（ゲーム開始前）のみ切り替え可
- **後方互換**: `mode` 未設定のルームは一致モードとして扱う
- **判定**: どちらのモードも主催者の手動判定（表記ゆれの扱いも主催者に委ねる）
